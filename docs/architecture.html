Morning Brief: architecture

Code computes the facts; the models write the words. One brief per traveller per day; Travezy's backend sends it.

Governance, across every layer

Judge and rubric (config), evaluation framework and scorecard, cost and speed tracking, budget cap, kill switch, notification controls (one per day, send window, time zone of the wake location, dedupe), privacy (no names, emails or phones to models; keys only in .env).
